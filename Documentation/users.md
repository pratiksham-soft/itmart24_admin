# Users Guide

This section has:

1. `Registered Users`
2. `Guest Users`
3. `Settings`

## How To Open Users

1. Log in to ITMart24 Admin.
2. Click `Users`.
3. Choose the page you need.

## Part 1: Registered Users

This page shows users who made real accounts.

### What You Can Do

- search users
- open profile
- check plan usage
- change access settings
- delete user

### How To Search Registered Users

1. Open `Users > Registered Users`.
2. Use the search box.
3. Type name, email, company, role, country, status, or ID.

### How To Open User Profile

1. Find the user row.
2. Click `View Profile`.
3. Read the user details.

### How To Manage Access

1. Open the user profile.
2. Go to `Plan Usage & Access`.
3. Check the user plan details.
4. Change the access settings if needed.
5. Click `Save Access Settings`.

### What You May See In Access Area

- current plan
- due date
- usage values
- unlimited mode
- plan rules

### How To Delete A Registered User

1. Find the user row.
2. Click `Delete`.
3. Type the needed confirmation name.
4. Click `Delete User`.

## Part 2: Guest Users

Guest users are visitors who did not fully register.

### What You Can Do

- search guest users
- check report activity
- check pricing activity
- check plan click activity
- export data

### How To Use Guest Users Page

1. Open `Users > Guest Users`.
2. Search by visitor details if needed.
3. Use duplicate filters if needed.
4. Read the activity list.
5. Export when needed.

### Export Options

1. CSV
2. XLSX

## Part 3: User Settings

This page controls storefront user settings.

### How To Use User Settings

1. Open `Users > Settings`.
2. Read the current values.
3. Change what you need.
4. Click `Save Settings`.

## Easy Daily Workflow

1. Check registered users first.
2. Open any important profile.
3. Fix plan access only when needed.
4. Check guest users for visitor activity.
5. Save user settings only after reviewing the change.
