# Vendors Guide

This page is for vendor records.

It helps you find, open, edit, and delete vendor data.

## How To Open Vendors

1. Log in to ITMart24 Admin.
2. Click `Vendors`.

## What You Can Do Here

- search vendors
- open vendor details
- edit vendor data
- delete vendor

## How To Search Vendors

1. Use the search box.
2. Type business name, contact name, email, phone, country, type, or ID.
3. Read the filtered list.

## How To Open Vendor Details

1. Find the vendor row.
2. Click `View`.
3. The vendor details window will open.

## What You Can Check Inside Vendor Details

1. Company overview
2. Contact and reachability
3. Business details
4. Media
5. Social links
6. System metadata
7. Advanced JSON editor

## How To Edit A Vendor

1. Open the vendor details window.
2. Change the fields you need.
3. Save the changes.

## Things You May Edit

- business name
- contact data
- address data
- logo and cover image data
- intro video data
- social links
- agreement accepted

## How To Delete A Vendor

1. Find the vendor row.
2. Click `Delete`.
3. Read the warning carefully.
4. Type the vendor name for confirmation.
5. Click `Delete Vendor`.

## Easy Tip

Use delete only when you are fully sure.

Vendor delete is shown as permanent delete.
