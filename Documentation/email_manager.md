# Email Manager Guide

This page is for mailbox work.

It helps you add email accounts, read inbox messages, and send emails.

## How To Open Email Manager

1. Log in to ITMart24 Admin.
2. Click `Marketing`.
3. Click `Email Manager`.

## What You Can Do Here

- add email account
- edit email account
- test email account connection
- read inbox folders
- search emails
- mark emails read or unread
- star or unstar emails
- delete emails
- download attachments
- compose new email
- reply
- forward

## 1. How To Add An Email Account

1. Open `Email Manager`.
2. Click `Add Account`.
3. Fill:
4. display name
5. email address
6. username
7. password
8. IMAP host and port
9. SMTP host and port
10. secure options
11. default account option
12. active account option
13. Click `Save Account`.

## 2. How To Test Connection

1. Save the account first.
2. Open the same account in edit mode.
3. Click `Test Connection`.
4. Check IMAP result.
5. Check SMTP result.

## 3. How To Open Mailbox Folders

1. Select the email account.
2. Look at the folder list.
3. Click a folder like `Inbox`, `Sent`, `Drafts`, `Spam`, or `Trash`.

## 4. How To Search Emails

1. Open the account.
2. Use the search box.
3. Type sender, subject, or message words.
4. Wait for the list to refresh.

## 5. How To Use Email Filters

1. Choose a filter mode.
2. You can use:
3. `All`
4. `Unread`
5. `Starred`
6. `Attachments`

## 6. How To Read One Email

1. Click the message in the message list.
2. Read the sender, receiver, date, and subject.
3. Read the body.
4. Scroll down to attachments if any.

## 7. How To Work With One Email

Inside one message, you can:

1. click `Mark Read` or `Mark Unread`
2. click `Star` or `Unstar`
3. click `Delete`
4. click `Download` for attachments

## 8. How To Send A New Email

1. Open Email Manager.
2. Select the sender account.
3. Click to compose a new email.
4. Fill `To`.
5. Fill `CC` or `BCC` if needed.
6. Write subject.
7. Write message.
8. Add files if needed.
9. Click `Send`.

## 9. How To Reply

1. Open the email message.
2. Click reply.
3. Check the receiver.
4. Write your message.
5. Click `Send`.

## 10. How To Forward

1. Open the email message.
2. Click forward.
3. Enter the new receiver.
4. Keep or remove old attachments as needed.
5. Click `Send`.

## 11. Why Email Manager Is Important

Email Campaigns use sender accounts from this page.

If there is no active email account here, email campaigns cannot send.

## Easy Daily Workflow

1. Check that the correct mailbox is selected.
2. Read unread messages first.
3. Reply where needed.
4. Test account connection if something looks broken.
5. Keep one account marked as default if your team uses one main sender.
