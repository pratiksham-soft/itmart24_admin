# Masters Guide

This section has system control pages.

Main pages:

1. `Sync`
2. `Manage Plans`
3. `User Plans`
4. `Monthly Target`
5. `Product Category Master`

## How To Open Masters

1. Log in to ITMart24 Admin.
2. Click `Masters`.
3. Choose the page you need.

## 1. Sync

This page is for sync and export type system work.

Use this page carefully.

Basic steps:

1. Open `Masters > Sync`.
2. Read the page cards and current status.
3. Open the correct sync or export action.
4. Review the options.
5. Start only the action you really need.
6. Wait for success or error message.

## 2. Manage Plans

This page is for subscription plan setup.

### What You Can Do

- create plan
- edit plan
- add periods
- add features
- add country pricing

### How To Create A Plan

1. Open `Masters > Manage Plans`.
2. Click `+ Create Plan`.
3. Fill plan name and details.
4. Add pricing periods.
5. Add features.
6. Add country pricing if needed.
7. Save the plan.

## 3. User Plans

This page is for user portal plans and one-time report plans.

### What You Can Do

- create user plan
- edit user plan
- view user plan
- manage one-time report plans

### Easy Steps

1. Open `Masters > User Plans`.
2. Choose the plan area you need.
3. Create or edit the plan.
4. Save the changes.

## 4. Monthly Target

This page is for monthly business goals.

### What You Can Manage

1. target revenue
2. target subscriptions
3. target vendor onboarding
4. planning notes

### How To Create Monthly Target

1. Open `Masters > Monthly Target`.
2. Click `+ Create Monthly Target`.
3. Choose the month.
4. Fill target revenue.
5. Fill target subscriptions.
6. Fill target vendor onboarding.
7. Add notes if needed.
8. Click `Save Target`.

### How To Edit Monthly Target

1. Find the target row.
2. Click `Edit`.
3. Change the values.
4. Save again.

## 5. Product Category Master

This page manages the product category tree.

### Category Types

1. Main Category
2. Sub Category
3. Sub Sub Category

### How To Create A Category

1. Open `Masters > Product Category Master`.
2. Click `+ Create Category`.
3. Choose category type.
4. If needed, select main category.
5. If needed, select sub category.
6. Type the category name.
7. Click `Save Category`.

### How To Delete A Category

1. Find the category in the tree.
2. Click the delete button.
3. Read the warning.
4. Confirm only if you are sure.

## Easy Tip

The `Masters` area can change big system data.

Please read carefully before saving.
