# Dashboard Guide

This page is the front page after login.

It helps you see important numbers very fast.

## What Dashboard Does

- shows business summary
- shows quick numbers
- helps you move to other sections fast

## How To Open Dashboard

1. Log in to ITMart24 Admin.
2. In the left menu, click `Dashboard`.
3. Open `Analytics`.

## What You Can See

1. Top summary cards
2. Business numbers
3. Quick action buttons
4. Helpful charts or overview boxes
5. `Dashboard > Visitors` for cross-portal visitor analytics

## How To Use Dashboard Step By Step

1. First look at the top number cards.
2. See which number is high and which number is low.
3. Check if there are new vendor, product, or business updates.
4. Use the quick buttons if you want to jump to another page.
5. Open the needed section from the left menu.

## Best Simple Way To Use Dashboard Every Day

1. Open dashboard in the morning.
2. Read the top summary cards.
3. Check support and notifications.
4. Check CRM if you need leads or campaigns.
5. Check products if product work is pending.

## Easy Reminder

Dashboard is for looking first.

Dashboard is not the main edit page.

It is the page that tells you where to go next.
