# Support Guide

This page is for support tickets.

A support ticket means a help message from a user or vendor.

## How To Open Support

1. Log in to ITMart24 Admin.
2. In the left menu, click `Support`.

## What You Can Do Here

- see all tickets
- search tickets
- filter tickets by status
- filter tickets by category
- open one ticket
- read full ticket details

## What You Can See On Top

1. All tickets count
2. Open tickets count
3. Resolved or closed tickets count

## How To Search Tickets

1. Find the search box.
2. Type ticket number, vendor name, email, category, or status.
3. Wait for the list to update.

## How To Filter Tickets

1. Use the `Status` filter.
2. Use the `Category` filter.
3. Pick the values you want.
4. Look at the new ticket list.

## How To Open A Ticket

1. Find the ticket in the table.
2. Click the ticket row or open button if shown.
3. Read the full ticket details.

## What You Can Check Inside A Ticket

1. Ticket ID
2. Ticket status
3. Category
4. Email or sender details
5. Created date
6. Full message
7. Related sections or linked details if available

## Easy Daily Work

1. Open `Support`.
2. Check open tickets first.
3. Use search or filters if the list is big.
4. Open one ticket at a time.
5. Read carefully before taking action.

## Simple Tip

Start with `Open` tickets first.

Then check `Resolved` or `Closed` only when you need old history.
