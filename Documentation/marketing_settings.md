# Marketing Settings Guide

This page helps choose which AI provider is used for marketing blog work.

There is also one small note about `SM Manager`.

## How To Open Marketing Settings

1. Log in to ITMart24 Admin.
2. Click `Marketing`.
3. Click `Settings`.

## What This Page Does

- choose AI provider
- save API keys for the selected provider

## AI Provider Choices

1. `OpenAI API`
2. `Groq + Replicate`

## How To Change AI Provider

1. Open `Marketing > Settings`.
2. Read the current provider.
3. Click the provider you want.
4. If you choose `Groq + Replicate`, fill:
5. `GROQ_API_KEY`
6. `REPLICATE_API_TOKEN`
7. Click `Save`.

## Easy Tip

Only change this page if you really need to change the blog AI backend.
