# Blog Manager Guide

This section has two main parts:

1. `Jobs`
2. `Blogs`

`Jobs` help create blog work.

`Blogs` help manage finished or saved blog posts.

## How To Open Blog Manager

1. Log in to ITMart24 Admin.
2. Click `Marketing`.
3. Click `Blog Manager`.
4. Choose `Jobs` or `Blogs`.

## Part 1: Blog Jobs

Blog jobs are repeat work rules.

They can use categories, topics, templates, and schedules.

### How To Create A Blog Job

1. Open `Marketing > Blog Manager > Jobs`.
2. Click `Create Job`.
3. Fill the job name.
4. Add blog categories.
5. Add topic lists.
6. choose the template
7. set the cron schedule
8. choose active or inactive
9. choose auto publish if needed
10. Save the job.

### What You Can Do In Blog Jobs

- create job
- edit job
- delete job
- turn job active or inactive
- run job one time now
- view logs
- copy logs
- save blog templates

### How To Run A Job One Time

1. Find the job in the table.
2. Make sure it is active.
3. Click `Run Once`.
4. Wait for the result message.

### How To Turn A Job On Or Off

1. Find the job row.
2. Use the toggle button.
3. Turn it on for active.
4. Turn it off for inactive.

### How To Read Logs

1. Click `View Logs`.
2. Read the latest entries.
3. Copy logs if you need to share them.

## Part 2: Blogs

Blogs are the blog posts themselves.

### How To Create A Blog

1. Open `Marketing > Blog Manager > Blogs`.
2. Click `Create Blog`.
3. Fill the blog form.
4. Save the blog.

### How To Filter Blogs

1. Use `Category filter`.
2. Use `Start date`.
3. Use `End date`.
4. Read the updated list.

### How To Work With A Blog

1. Click `View` to read the blog.
2. Click `Edit` to change it.
3. Click `Delete` to remove it.
4. Click `Publish` to send it to Shopify.

### Blog Status Meaning

1. `draft` = saved, not ready yet
2. `generated` = created by the system
3. `published` = sent to Shopify
4. `publish_failed` = publish did not finish correctly

## Easy Safe Workflow

1. Create or check a blog job.
2. Run the job if needed.
3. Open `Blogs`.
4. Review the blog text.
5. Edit if needed.
6. Publish to Shopify only after checking the content.
