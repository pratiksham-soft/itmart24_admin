# Segments Guide

Segments are smart groups.

They help you make reusable audiences for CRM work and campaigns.

## How To Open Segments

1. Click `Marketing`.
2. Click `CRM`.
3. Click `Segments`.

## What You Can Do

1. create segment
2. edit segment
3. preview segment
4. delete segment

## What A Segment Has

1. segment name
2. description
3. entity type
4. match type
5. conditions

## Entity Type Choices

1. leads
2. contacts
3. companies
4. deals

## Match Type Choices

1. `all` = every condition must match
2. `any` = even one condition can match

## How To Create Segment

1. Click `Create Segment`.
2. Write the segment name.
3. Choose entity type.
4. Choose match type.
5. Add the rules in the segment builder.
6. Save the segment.

## Example Conditions

1. leadStatus equals Qualified
2. country equals India
3. tags contains vendor
4. dealValue greater than a number

## How To Preview Segment

1. Find the segment row.
2. Click `View`.
3. The preview window shows matching record count and sample data.

## Why Segments Are Useful

1. better campaign targeting
2. quick filtered groups
3. repeated CRM work becomes easier
