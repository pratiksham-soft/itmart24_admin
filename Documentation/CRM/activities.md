# Activities Guide

This page is the CRM history page.

It shows what happened in CRM.

## How To Open Activities

1. Click `Marketing`.
2. Click `CRM`.
3. Click `Activities`.

## What You Can Do

1. search activity
2. filter by activity type
3. filter by entity type
4. read timeline history

## Activity Type Examples

1. Lead Created
2. Lead Updated
3. Lead Converted
4. Contact Created
5. Company Created
6. Deal Created
7. Deal Stage Changed
8. Task Created
9. Task Completed
10. Note Added
11. Email Sent
12. Campaign Created
13. Campaign Sent

## Entity Type Examples

1. lead
2. contact
3. company
4. deal
5. campaign
6. segment

## How To Use Activities

1. Search by name or keyword if needed.
2. Filter by activity type if needed.
3. Filter by entity type if needed.
4. Read the timeline from latest to older.

## Why This Page Is Useful

1. to check who did what
2. to check when something changed
3. to understand old CRM history
4. to check campaign and follow-up work
