# Reports Guide

This page helps measure CRM performance.

## How To Open Reports

1. Click `Marketing`.
2. Click `CRM`.
3. Click `Reports`.

## Date Range Buttons

1. Last 7 days
2. Last 30 days
3. Last 90 days

## What The Page Shows

Top numbers:

1. Total Leads
2. Converted Leads
3. Conversion Rate

Charts:

1. Lead Funnel
2. Lead Source Report
3. Task Productivity
4. Sales Pipeline Value

Other blocks:

1. Owner Performance
2. Campaign Report

## How To Use Reports

1. choose the date range
2. read the top numbers
3. check the lead funnel
4. check which lead source gives better results
5. check task productivity
6. check pipeline value
7. read owner performance
8. read campaign report

## Why This Page Matters

1. it shows if lead quality is good
2. it shows if follow-up work is happening
3. it shows if deals are moving
4. it shows if campaigns are helping
