# Tasks And Follow-ups Guide

This page is for planned work.

It helps the team remember who to call, mail, meet, or follow up.

## How To Open Tasks

1. Click `Marketing`.
2. Click `CRM`.
3. Click `Tasks & Follow-ups`.

## What You Can Do

1. create task
2. search task
3. filter by status
4. filter by priority
5. edit task
6. mark task completed
7. delete task

## Task Status List

1. `Pending`
2. `In Progress`
3. `Completed`
4. `Cancelled`

## Task Type Examples

1. Call
2. Email
3. Meeting
4. Demo
5. Proposal
6. Follow-up
7. Internal Note
8. Other

## How To Create Task

1. Click `Create Task`.
2. Fill task title.
3. choose task type
4. choose status
5. choose priority
6. set due date
7. link the related record if needed
8. save task

## What Related To Means

The task can point to:

1. lead
2. contact
3. company
4. deal

## How To Complete Task

1. Find the task row.
2. Use `View` on the row.
3. If the task is not completed, the system marks it completed.

## Good Task Rule

If a lead is active, there should usually be a next task.
