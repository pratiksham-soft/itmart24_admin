# CRM Settings Guide

This page controls CRM default values.

It is a system settings page.

## How To Open CRM Settings

1. Click `Marketing`.
2. Click `CRM`.
3. Click `CRM Settings`.

## What You Can Edit

1. lead statuses
2. lead sources
3. deal stages
4. task types
5. contact types
6. default currency
7. assignment rules
8. email campaign defaults
9. CRM permissions

## How To Use This Page

1. Open the page.
2. Wait for current settings to load.
3. Edit the needed value list or JSON block.
4. Click `Save Settings`.

## Important Parts

### Lead Statuses

These control the lead journey choices.

### Lead Sources

These tell where leads came from.

### Deal Stages

These control the deal pipeline steps.

### Task Types

These control task dropdown choices.

### Default Currency

This controls the default money unit used in CRM.

### Assignment Rules

This controls how CRM items may be assigned.

### Email Campaign Defaults

This controls default campaign behavior.

### CRM Permissions

This controls who can do which CRM actions.

## Careful Note

This page changes CRM behavior for everyone.

So please save only after checking the values carefully.
