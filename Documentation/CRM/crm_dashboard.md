# CRM Dashboard Guide

This page is the CRM summary page.

It helps you quickly see what is happening in the CRM.

## How To Open CRM Dashboard

1. Log in to ITMart24 Admin.
2. Click `Marketing`.
3. Click `CRM`.
4. Click `CRM Dashboard`.

## What You Can See

Top summary cards:

1. Total Leads
2. New Leads
3. Qualified Leads
4. Active Deals
5. Won Deals
6. Lost Deals
7. Pending Follow-ups
8. Overdue Tasks
9. Campaigns Sent
10. Conversion Rate

Charts and blocks:

1. Leads by Source
2. Deals by Stage
3. Monthly Lead Growth
4. Revenue Forecast
5. Recent Activity
6. Today's Follow-ups
7. Task Completion Overview
8. Quick Actions

## How To Use This Page

1. Look at the top cards first.
2. Check if new leads are growing.
3. Check if overdue tasks are too many.
4. Check how many deals are won and lost.
5. Read `Recent Activity` for the latest CRM work.
6. Read `Today's Follow-ups` so no task is missed.
7. Use `Quick Actions` to jump fast to:
8. Add Lead
9. Add Contact
10. Add Company
11. Add Deal
12. Create Task
13. Create Campaign

## What This Page Is Best For

1. morning CRM check
2. manager review
3. checking team progress
4. seeing what needs attention first

## Easy Tip

If `Overdue Tasks` is high, fix that first.

If `New Leads` is high, check `Leads` next.
