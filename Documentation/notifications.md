# Notifications Guide

This page shows new admin alerts.

These alerts can come from vendors, products, or support tickets.

## How To Open Notifications

1. Log in to ITMart24 Admin.
2. In the left menu, click `Notifications`.

## What You Can Do Here

- see all notifications
- see unread count
- open the related page
- mark one notification as read
- mark all notifications as read

## What You See On Top

1. Total notification count
2. Unread notification count
3. `Mark all as read` button

## How To Read Notifications

1. Open the page.
2. Look at the newest notification first.
3. Read the title.
4. Read the message.
5. Check the type badge.
6. Check the date and source ID.

## How To Open The Related Page

1. Find the notification you want.
2. Click `Open`.
3. The system will take you to the related page.

## How To Mark One Notification As Read

1. Find the unread notification.
2. Click `Mark as read`.
3. The unread badge will change.

## How To Mark All Notifications As Read

1. Go to the top area.
2. Click `Mark all as read`.
3. Wait for the page to refresh.

## Easy Tip

Read unread items first.

If the message needs action, click `Open` right away.
