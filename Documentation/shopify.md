# Shopify Guide

This section has:

1. `Shopify Products`
2. `Shopify Collections`

## How To Open Shopify Section

1. Log in to ITMart24 Admin.
2. Click `Shopify`.
3. Choose the page you need.

## Part 1: Shopify Products

This page helps you see products that are connected to Shopify.

### What You Can Do

- search products
- use filters
- export data
- open the real Shopify product
- manage product collections

### How To Search Shopify Products

1. Open `Shopify > Shopify Products`.
2. Use the search box.
3. Type the product name or other needed words.

### How To Export Shopify Products

1. Set filters if needed.
2. Click one export button.
3. Choose:
4. `Export JSON`
5. `Export CSV`
6. `Export PDF`

### How To Open The Real Shopify Product

1. Find the product row.
2. Click `Open product`.

### How To Manage Product Collections

1. Find the product row.
2. Click the collection manage button.
3. Search collections if needed.
4. Select or unselect collections.
5. Save changes.

Important:

Saving updates Shopify immediately.

## Part 2: Shopify Collections

This page is for Shopify collection records.

### What You Can Do

- search collections
- filter collections
- export collections
- create collection
- open real collection
- publish collection
- unpublish collection
- delete collection

### How To Create A Collection

1. Open `Shopify > Shopify Collections`.
2. Click the create button.
3. Fill the collection details.
4. Save it.

### How To Publish Or Unpublish A Collection

1. Find the collection row.
2. Click the publish action.
3. Read the popup carefully.
4. Confirm publish or unpublish.

### How To Open The Real Shopify Collection

1. Find the collection row.
2. Click `Open collection`.

### How To Export Collections

1. Apply filters if needed.
2. Choose:
3. `Export JSON`
4. `Export CSV`
5. `Export PDF`

## Easy Tip

Check carefully before saving collection changes.

Shopify updates are important and can affect the live store.
